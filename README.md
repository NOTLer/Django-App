# Django First App

Этот репозиторий содержит Django-приложение `first_app`, которое представляет собой базовый интернет-магазин или каталог товаров.

## Описание проекта

Приложение реализует следующую функциональность:

*   **Модели данных (Data Models):**
    *   `Category` (Категория): Содержит название категории и изображение.
    *   `Product` (Товар): Содержит информацию о товаре (название, бренд, страна, размер, цена, изображение) и связь с категорией через внешний ключ.
    *   Модель `Employee` (Сотрудник) закомментирована и может быть использована в будущем.

*   **Административный интерфейс (Admin Interface):**
    *   Модели `Category` и `Product` готовы к регистрации в панели администратора Django для удобного управления данными (добавление, редактирование, удаление).

*   **Веб-представления (Views):**
    *   `first_app/`: Простое приветственное сообщение.
    *   `about/`: Страница "О сайте", которая отображает информацию и меню.
    *   `main/`: Главная страница сайта.
    *   `portfolio/`: Страница "Портфолио".
    *   `json/`: Пример API-эндпоинта, возвращающего данные в формате JSON.
    *   `img/`: Эндпоинт для отдачи файлов (в данном случае изображения).

*   **Шаблоны (Templates):**
    *   Используются HTML-шаблоны, расположенные в директории `project/` (например, `about.html`, `main.html`, `portfolio.html`), для рендеринга страниц.
